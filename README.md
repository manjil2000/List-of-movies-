# CineVault
PHP, MySQL, Twig and AJAX movie collection example. Requires PHP 8.1+, PDO MySQL, mbstring and Twig 3. Install Twig using Composer in the parent public_html directory. Use existing movies and movie_users tables. Create cinevault_config.php outside public_html using the example provided separately, with university-approved restricted read access for the PHP service. Never commit credentials. Test CRUD, combined filters, authentication, CAPTCHA and CSRF before deployment. Arithmetic CAPTCHA is basic and not robust bot protection. All authenticated accounts share the collection.
